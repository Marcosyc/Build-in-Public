# Build-in-Public
Estarei criando esse projeto para registrar meu avanço na plataforma GitHub e meus passos como desenvolvedor.

# Primeira paragrafo aí

Comecei vendo tutoriais que me guiavam para baixar ou arrumar coisas no GitHub. Só clicava no que diziam e fé, mas agora quero entender como foi feito todo esse desenvolvimento para que eu só clicasse no link e conseguisse oq preciso.
Oq eu tenho em mente é poder criar umas coisas aí para ajudar a galera também e claro conseguir uma experiência no barato.
